# Frontseat releases

The released builds of [Frontseat](https://frontseat.dev): the `frontseat` CLI, its Linux launchers (`fsexec`) and every plugin's wasm module, one GitHub release per version, each with its `checksums.txt`.

Install with [mise](https://mise.jdx.dev) through the [frontseat backend](https://github.com/frontseat-dev/frontseat-mise):

```toml
[plugins]
frontseat = "https://github.com/frontseat-dev/frontseat-mise"

[tools]
"frontseat:cli" = "0.49.1"
```

This repository holds releases only. Its tags are the release versions; the source is not published here.
